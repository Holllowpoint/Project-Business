# Project-Business

A small Python project built while learning GUI work, image generation, and
local databases.

## What it does

`prototype.py` generates a simple crate sprite with Pillow and saves it to the
`assets` folder.

## Requirements

- Python 3.10 or newer
- Pillow

```bash
python -m pip install pillow
```

## Running

```bash
python prototype.py
```

This creates `assets/crate2.png`.

## Project structure

```
.
├── prototype.py      # Sprite generator
├── assets/           # Generated images
└── README.md
```

## Notes

The `.db` files are local test data and are not tracked in git.
